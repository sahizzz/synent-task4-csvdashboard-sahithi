# Interactive Data Analytics Dashboard

## Synent Technologies Internship - Task 4

### Project Overview

This project is an interactive CSV Data Analytics Dashboard developed using Streamlit, Pandas, Matplotlib, and Seaborn.

The dashboard allows users to upload CSV files and perform data analysis interactively through charts, statistics, filtering, and correlation analysis.

---

# Features

## Dataset Analysis

- Dataset preview
- Last 5 rows
- Random sample data
- Dataset shape
- Column names
- Data types
- Summary statistics

## Missing Value Analysis

- Missing value count
- Missing value percentage

## Visualizations

- Histogram
- Scatter Plot
- Line Chart
- Box Plot
- Pie Chart
- Correlation Heatmap

## Interactive Features

- Dataset filtering
- Dataset searching
- Categorical value counts
- Download processed dataset

# Installation

Install required libraries:

```bash
pip install -r requirements.txt
```

---

# Run the Dashboard

Use this command:

```bash
streamlit run app.py
```

If streamlit command does not work:

```bash
py -m streamlit run app.py
```

---

# Dashboard Functionalities

## Upload CSV File

Users can upload any CSV dataset for analysis.

## Data Visualization

The dashboard automatically generates multiple visualizations from uploaded data.

## Correlation Analysis

Heatmaps and correlation tables help identify relationships between variables.

## Filtering and Search

Users can filter rows and search values interactively.

## Download Dataset

Processed dataset can be downloaded directly from the dashboard.
